# CMIP7-Input Python API Reference

Welcome to the technical API reference documentation for the Python codebase in [ACCESS-NRI/CMIP7-Input](https://github.com/ACCESS-NRI/cmip7-input).

The `esm1p6_ancil` Python package powers data ingestion, validation, coordinate transformation, temporal interpolation, and UM ancillary generation across historical, pre-industrial, emission-driven, and future projection climate experiments.
