# Aerosol Emissions Pipeline

The aerosol emissions pipeline processes anthropogenic and biomass burning emissions across four species: Black Carbon (`BC`), Biomass (`Bio`), Organic Carbon (`OC`), and Sulfur Dioxide (`SO2`).
