Carbon Dioxide (CO2) Fluxes
===========================

The CO2 pipeline generates spatially gridded monthly surface CO2 emission ancillaries for interactive carbon-cycle experiments (``esm-hist``, ``esm-ssp``) and CDR benchmarks (``flat10-cdr``).
